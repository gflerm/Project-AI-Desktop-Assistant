Project TARS --- Apache License 2.0 Selection

The adopted default licence for original Project TARS software deliberately released as open source is the Apache
License, Version 2.0.

Before a public release, place the unmodified official Apache License
2.0 text in the repository root as `LICENSE`.

SPDX-License-Identifier: Apache-2.0

IMPORTANT: - This selection applies only to original Project TARS
material explicitly released under Apache-2.0. - Third-party libraries,
models, voices, datasets, assets and services retain their own
licences/terms. - No rights to third-party fictional characters, names,
trademarks, voices, artwork or other protected assets are granted. -
Project branding/trademark rights are not granted merely by the software
licence. - The existing proprietary Project TARS policy must be
reconciled before a public open-source release.

See `Project-TARS-Open-Source-Licensing-Strategy.md` for the
project-wide licensing architecture and release checklist.
