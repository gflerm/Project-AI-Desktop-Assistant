# Project TARS --- Apache License 2.0 Selection

**Status:** Version 0.2 --- Reconciled selection record\
**Date:** 2026-08-09

The adopted default licence for original Project TARS software deliberately
selected for open-source release is the **Apache License, Version 2.0**.

Before a public release, place the unmodified official Apache License 2.0
text in the repository root as `LICENSE`.

```text
SPDX-License-Identifier: Apache-2.0
```

Important boundaries:

- This selection applies only to original Project TARS software explicitly
  released under Apache-2.0.
- Private or unreleased project material remains All Rights Reserved unless
  explicitly licensed otherwise.
- Third-party libraries, models, voices, datasets, assets and services
  retain their own licences and terms.
- No rights to third-party fictional characters, names, trademarks, voices,
  artwork or other protected assets are granted.
- Project branding and trademark rights are not granted merely by the
  software licence.
- The staged project policy is reconciled at policy level. Every public
  release still requires component-level scope, provenance, notice and
  compatibility checks.

See `Project-TARS-Open-Source-Licensing-Strategy.md` for the project-wide
licensing architecture and release checklist.
