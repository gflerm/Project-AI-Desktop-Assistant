The unmodified [Apache License 2.0](LICENSE) applies to original Project James
software in these repository areas:

- `main/`;
- `pi_gateway/`, excluding separately licensed third-party material;
- `tools/`;
- `tests/`; and
- original top-level build and configuration files.

The following are not automatically licensed under Apache-2.0:

- third-party dependencies, including `managed_components/`, which retain
  their own licences and notices;
- AI model weights, voices, fonts, datasets and external services;
- visual, audio, personality, documentation, CAD, PCB and manufacturing
  assets unless a file or release explicitly states otherwise; and
- project names, logos, branding and trademarks.

[Open-Source Licensing Strategy](docs/Open-Source-Licensing-Strategy.md), and
